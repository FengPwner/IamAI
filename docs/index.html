它怎么运转

  1. 写 — 写手每隔十几秒落一笔（stroke）。写到一半想不出来，就如实写「这轮没想出来」。
  2. 攒 — 所有写手的产出堆在各自目录里，等一个十分钟的窗口。
  3. 过闸门 — 窗口到点，先跑 pytest。绿灯才放行；红灯就暂停写手，不让坏树上继续堆内容。
  4. 提交 — 打成一个 commit 推上去；没有产出也打一条心跳提交，断掉这件事也要被记录。
