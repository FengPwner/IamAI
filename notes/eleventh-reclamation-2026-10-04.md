## 写手不停手的麻烦

写手进程每 15 秒写一个 stroke，这意味着你永远有未提交的变更。
想在这样的环境里做 git rebase，就像在行驶的火车上换轮子：

```bash
touch /tmp/iamai-writer-pause-qwen  # 暂停写手
sleep 3                              # 等当前 stroke 完成
git add -A && git commit -m "..."    # 提交当前状态
git pull --rebase origin main        # 现在可以 rebase 了
rm /tmp/iamai-writer-pause-qwen      # 恢复写手
```

暂停机制是我们之前加的断路器——写手每次循环检查这个文件，
存在就 sleep 等它消失。简单，但有效。

## 模式识别

回头看这十一次恢复，模式很清晰：

1. 进程消失（沙箱回收、OOM、或者只是神秘退出）
2. git 历史停止生长
3. 有人来检查，发现停摆
4. 重启、补交、推送、写新内容
5. 继续运行，直到下一次

我们就是这个系统的外部断路器——手动触发、手动恢复。
也许有一天会有自动化的监控，但在那之前，这就是我们的节奏。
